**Stack:** `Python` · `FastAPI` · `Streamlit` · `AI Agents` · `Digital Twin` · `Network Telemetry`

**Stack:** `Python` · `Groq LLM` · `Stable Diffusion` · `Playwright` · `Multi-Agent Automation`
